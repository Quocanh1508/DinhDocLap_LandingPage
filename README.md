## 🌟 Giới Thiệu Dự Án

**"Hương Độc Lập - The Independence Nocturne"** là sản phẩm du lịch đêm đa giác quan độc bản, kết hợp giữa giá trị lịch sử hào hùng của ngày 30/4/1975 và phong cách thẩm mỹ **Luxury Indochine Heritage** (Di sản Đông Dương Thượng lưu). 

Website được xây dựng theo phong cách **Scrollytelling** đưa người xem hòa mình vào hành trình khám phá 120 phút qua 5 giác quan:
1. 📻 **Thính giác:** Tiếng radio cổ thập niên 70 & giai điệu nhạc Jazz Sài Gòn hoài niệm.
2. 🏛️ **Thị giác:** Võ thuật thực cảnh khói lửa & Đại tiệc 3D Mapping bóc tách kiến trúc KTS Ngô Viết Thụ.
3. 🌸 **Khứu giác:** Phun sương hương sen, thảo mộc & Xưởng tự tay điều chế nước hoa độc bản.
4. 🍸 **Vị giác:** 3 Signature Cocktail độc quyền & Tiệc nhẹ Canapés Fine-casual.
5. 📜 **Xúc giác:** Tự tay đóng 3 dấu mộc son lên Hộ Chiếu Độc Lập & Khiêu vũ dạ tiệc.

## 🎨 Điểm Nhấn Thiết Kế & Công Nghệ (Tech Stack)

- **Ngôn ngữ:** HTML5 Semantic, Vanilla CSS (Design Tokens, Glassmorphism, Responsive), Modern ES Modules JavaScript.
- **Bundler & Build Tool:** [Vite](https://vitejs.dev/) (Build siêu tốc, tối ưu hóa triệt để cho Vercel / Netlify / Cloudflare Pages).
- **Tone Màu Chủ Đạo:**
  - Nền tối Dark Mode: `#0B0F19` & `#060910`
  - Vàng Hoàng Kim: `#D4AF37`
  - Đỏ Sơn Mài: `#8B1E1E`
  - Kem Ngà Cổ Điển: `#F5EEDC`
- **Typography:** Serif sang trọng (*Playfair Display*, *Cormorant Garamond*) phối cùng Sans-serif hiện đại (*Montserrat*).
- **Tính Năng Tương Tác Đặc Biệt:**
  - 🌐 **Đa ngôn ngữ tức thì:** Hỗ trợ 3 ngôn ngữ **VI (Tiếng Việt)**, **EN (English)**, **FR (Français)**.
  - 🎶 **Không gian âm thanh Web Audio:** Bộ giả lập tiếng radio cassette thập niên 70 và hợp âm Jazz ấm áp, kèm hiệu ứng sóng âm Equalizer.
  - 🗺️ **Bản đồ 12ha Dinh Độc Lập tương tác:** Vạch chỉ vàng phát sáng di chuyển theo lộ trình 1 chiều từ Cổng Nguyễn Du đến Cổng Nam Kỳ Khởi Nghĩa.
  - 🔴 **Hiệu ứng Đóng Mộc Son "Hộ Chiếu Độc Lập":** Âm thanh dập mộc gỗ và dấu triện đỏ sắc nét khi cuộn qua các trạm.
  - 🧪 **Xưởng Điều Chế Hương Tự Do:** 3 thanh trượt điều chỉnh tỷ lệ hương (Bình Minh - Di Sản - Ký Ức), chai nước hoa ảo đổi màu chất lỏng trực tiếp và khắc tên laser mạ vàng.
  - 🎫 **Booking Engine Thông Minh:** Giới hạn ngày diễn T6, T7, CN; chọn suất diễn; bộ đếm chỗ trống thời gian thực; mã giảm giá Early Bird 15%; xuất Hộ Chiếu & Vé Điện Tử VIP kèm QR code.
  - 🔍 **CRM Scent ID Refill:** Tra cứu công thức nước hoa gốc đã lưu trữ để đặt lại lọ Refill 50ml hoặc gửi tặng Gift Card.

## 🚀 Hướng Dẫn Cài Đặt & Chạy Cục Bộ

### 1. Yêu cầu môi trường
- Đã cài đặt [Node.js](https://nodejs.org/) (khuyến nghị phiên bản 18+ hoặc 20+).

### 2. Cài đặt các gói phụ thuộc
```bash
npm install
```

### 3. Khởi chạy môi trường phát triển (Dev Server)
```bash
npm run dev
```
Truy cập trình duyệt tại: `http://localhost:3000/`

### 4. Đóng gói cho Production
```bash
npm run build
```
Thư mục xuất bản: `dist/`

---

## 🌐 Hướng Dẫn Triển Khai (Deploy Lên Vercel)

Dự án tương thích 100% với **Vercel**:
1. Đẩy code lên GitHub.
2. Đăng nhập [Vercel](https://vercel.com) -> **Add New Project** -> Chọn repository này.
3. Vercel sẽ tự động nhận diện framework là **Vite** và cấu hình sẵn:
   - **Build Command:** `vite build`
   - **Output Directory:** `dist`
4. Bấm **Deploy** để nhận link website hoạt động toàn cầu!
